# AnyBuff v1.3.2

Six UI refinements.

- **Copy button on user messages** — next to Revert, matching agent messages.
- **Remembers the last-used project** — restarts reopen your last project; deleted projects can no longer reappear.
- **Follow System theme works on Windows** — the title bar and UI now track the OS dark/light setting live.
- **Diagnostics ✕ returns to About** — the window layers over Settings instead of dropping to the main page.
- **Chat-area right-click menu** — Select All (scoped to the clicked message) and Copy; the composer menu also offers Cut/Paste, and the menu width now hugs its text.
- **Composer draft memory** — unsent text survives switching conversations or pages and never leaks into other conversations.

**Download:** `AnyBuff-Setup-1.3.2.exe` (unsigned — SmartScreen's "Unknown publisher" warning is expected; More info → Run anyway). Auto-updates via electron-updater.
