# AnyBuff v1.3.2

六大介面優化與穩定性修正。／Six UI refinements and reliability fixes.

## ✨ 改進 ／ Improvements

- **使用者訊息複製按鈕** ／ **Copy button on user messages**
  自己的訊息 footer（Revert 旁）新增複製按鈕，與 agent 訊息一致。／Your own messages now have a copy button next to Revert, matching agent messages.

- **記住最後使用的專案** ／ **Remembers your last-used project**
  重開程式會回到上次工作的專案；已刪除的專案不會再出現（切換專案即持久化、移除專案時同步清除、啟動時自動修復懸空記錄）。／Reopening the app returns you to the project you were last working in; a deleted project can no longer reappear (cwd is persisted on switch, cleared on removal, and self-heals on boot).

- **Follow System 佈景主題在 Windows 生效** ／ **Follow System theme works on Windows**
  選擇「跟隨系統」後，Windows 標題列與介面會即時跟隨系統深淺色切換（Android 行為不變）。／With Follow System selected, the title bar and UI now track the OS dark/light setting live on Windows (Android unchanged).

- **Diagnostics 關閉後回到 About** ／ **Diagnostics X returns to About**
  診斷視窗改為疊在設定頁上層，按 ✕ 回到 Settings → About 而不是主頁面。／The diagnostics window now layers over Settings, so closing it lands back on Settings → About instead of the main page.

- **對話區右鍵編輯選單** ／ **Chat-area right-click edit menu**
  在訊息區按右鍵可選單操作：Select All（只選該則訊息）、Copy；在輸入框按右鍵另有 Cut／Paste。選單寬度貼合文字。／Right-clicking a message offers Select All (scoped to that single message) and Copy; the composer additionally offers Cut/Paste. The menu width now hugs its text.

- **輸入框草稿記憶** ／ **Composer draft memory**
  未送出的訊息在切換對話或頁面後仍會保留，回到原對話即恢復，且不會跑到其他對話的輸入框。／Unsent composer text survives switching conversations or pages and is restored when you return — never leaking into another conversation's input.

## 🔧 其他 ／ Internals

- host-core：`touchProject` upsert、`getAppSettings` cwd 自癒、`removeProject` 清除 cwd，新增 dispatcher 測試（103/103 通過）。／host-core: touchProject upsert, getAppSettings cwd self-heal, removeProject cwd clearing, with new dispatcher tests (103/103 passing).
