# AnyBuff v1.7.0 — The reviewer can see the diff

## Highlights

- **The reviewer now sees what actually changed.** A subagent's edits used to
  reach the reviewer as nested JSON in DEFAULT mode, and as nothing but a file
  list in MAX mode — so a review could only repeat the request or guess. Subagent
  results now arrive as readable text: the path, the exact old/new strings,
  whole-file writes, and each result attached to the edit it belongs to. MAX mode
  additionally returns the unified diff that its multi-prompt editor applied.
- **No private reasoning in the review.** The reviewer inherits visible text,
  tool calls and tool results, but not the author's internal monologue.
- **Cheaper session start.** The startup Git snapshot is now status plus recent
  commit subjects — ~13k characters worst case, down from ~66k. The two 30k diffs
  only covered tracked files (new files never appeared) and went stale the moment
  work began, so diffs are fetched on demand instead. A prompt that told the
  model to avoid a `git_status` tool that does not exist is gone.
- **Task cost in the composer**, and a capabilities editor that shows effective
  values (settings → measured → catalog) instead of raw JSON.
- **Catalog refreshes only when configuration changes**, so startup and idle use
  stay offline.

### Updating

- **Windows** — install `AnyBuff-Setup-1.7.0.exe` (unsigned, so SmartScreen
  shows "Unknown publisher": *More info → Run anyway*). Existing installs detect
  and apply the update automatically.
- **Android** — install `AnyBuff-1.7.0-android-arm64.apk` over v1.6.0; it is
  signed with the same release key and carries a higher version code, so it
  updates in place without uninstalling.
