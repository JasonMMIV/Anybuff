# AnyBuff v1.7.1 — /compact keeps your history

## Fixes

- **`/compact` no longer erases the conversation when the summary fails.** An
  empty stop, a reasoning-only or tool-only reply, or a step that ended with an
  error used to replace the entire history with an empty summary — the model
  simply "forgot" everything. AnyBuff now keeps the original history and shows
  a visible system note explaining that compaction did not run and can be
  retried. A clean summary still replaces the history as before.
- **Commits no longer carry a Codebuff signature.** The `run_terminal_command`
  commit guide stopped asking for the `Generated with Codebuff` line and the
  `Co-Authored-By: Codebuff` trailer, and the tool example no longer shows one.
  Commits authored in AnyBuff belong to you.
- **Android: conversation export works.** The Export action now writes the
  Markdown to the share sheet (Files, Drive, mail) instead of reporting that
  export is unsupported.
- **Android: the composer stays on one row** when the cost badge is visible;
  the amount is stacked inside the token pill and remains available in the
  popover.

### Updating

- **Windows** — install `AnyBuff-Setup-1.7.1.exe` (unsigned, so SmartScreen
  shows "Unknown publisher": *More info → Run anyway*). Existing installs
  detect and apply the update automatically.
- **Android** — install `AnyBuff-1.7.1-android-arm64.apk` over v1.7.0; it is
  signed with the same release key and carries version code 10701, so it
  updates in place without uninstalling.
