# AnyBuff v1.6.0 — Model catalog & reasoning dialects

## Highlights

- **Every model is known before the first request.** A models.dev catalog is
  now baked into the app (8,400+ provider/model entries, about 1 MB): context
  window, max output, vision support, reasoning options and pricing are
  resolved for models AnyBuff has never seen — including on providers you
  named yourself (`my-claude`, a local gateway, …).
- **Your settings still win.** Resolution is explicit settings → what AnyBuff
  actually measured on your endpoint → catalog → defaults. A context window
  learned from a real overflow is never clamped down by a catalog number, and
  catalog values are never written into your config.
- **One reasoning shape per endpoint.** The model editor gained a
  **Reasoning parameter format** picker: `reasoning_effort`, `thinking_budget`,
  `enable_thinking`, nested `reasoning { effort }`, Anthropic
  `output_config.effort` and extended-thinking `budget_tokens` — plus a
  no-parameter choice that omits the key instead of sending an explicit "off".
- **Cost estimates follow the invoice.** Cached input, cache writes, reasoning
  tokens and >200k context tiers are priced when the catalog knows them.
- **Offline by default, refresh on demand.** Startup never touches the
  network; a refresh fetches models.dev with ETag/304 and replaces the cache
  atomically.

Works on Windows and Android — the same host logic runs in both shells.

### Updating

- **Windows** — install `AnyBuff-Setup-1.6.0.exe` (unsigned, so SmartScreen
  shows "Unknown publisher": *More info → Run anyway*). Existing installs
  detect and apply the update automatically.
- **Android** — install `AnyBuff-1.6.0-android-arm64.apk` over v1.5.0; it is
  signed with the same release key and carries a higher version code, so it
  updates in place without uninstalling.
