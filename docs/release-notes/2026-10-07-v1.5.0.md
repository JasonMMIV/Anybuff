# AnyBuff v1.5.0 — Send now

## Highlights

- **Send now — steer a run that is already going.** `Ctrl`/`Cmd`+`Enter`, or the
  new **Send now** button next to the send button, hands a plain-text draft to
  the running turn: the agent answers it at its next step boundary and the run
  keeps going, so you no longer have to wait out a long turn to correct course.
  Plain `Enter` is unchanged — it still queues the message for after the turn.
- **Nothing you type is lost.** If the run ends (or you stop it) before your
  steered message is picked up, it goes back to the front of the queue, in the
  order you sent it. After a **Stop**, the queue stays paused until you resume
  it, so a message you sent while stopping cannot silently restart the turn.
- **The entry only appears when it is faithful.** Attachments, slash commands
  and pending `!command` output still queue — those cannot be injected without
  changing what the model sees. A message you send with Send now is answered
  ahead of anything already parked in the queue, by design.
- **Message timestamps joined the actions.** A timestamp now reveals together
  with the copy/revert buttons on hover instead of sitting in the footer, so a
  finished conversation reads as prose rather than chrome.

Works on Windows and Android — the same host logic runs in the desktop app and
in the Android sandbox.

### Updating

- **Windows** — install `AnyBuff-Setup-1.5.0.exe` (unsigned, so SmartScreen
  shows "Unknown publisher": *More info → Run anyway*). Existing installs
  detect and apply the update automatically.
- **Android** — install `AnyBuff-1.5.0-android-arm64.apk` over v1.4.0; it is
  signed with the same release key and carries a higher version code, so it
  updates in place without uninstalling.
